# Portable DC-UPS / Power Hub

## 1. Архитектура системы
```mermaid
flowchart TB

    AC["230 В AC<br/>Электросеть"]
    SOL["Мобильная<br/>солнечная панель"]

    AC --> AC_PROT["Входная защита<br/>предохранитель • выключатель • EMI"]
    AC_PROT --> PSU["Mean Well AC/DC<br/>230 В → 28–30 В DC<br/>150–180 Вт"]

    SOL --> MPPT["MPPT / Solar DC-DC"]

    PSU --> PWRPATH["Power Path / DC BUS"]
    MPPT --> PWRPATH

    PWRPATH --> CHARGER["CC/CV зарядное устройство<br/>25,2 В / 4 А"]

    CHARGER --> BMS["BMS 6S"]
    BMS --> BAT["Li-ion аккумулятор<br/>6S6P<br/>21,6 В ном. / 25,2 В max"]

    BAT --> DCUPS["Buck-Boost DC/DC<br/>19,0 В / до 8 А"]

    PWRPATH --> DCUPS

    DCUPS --> LOADS["Распределение DC-питания"]

    LOADS --> PC["AOOSTAR GEM12+ PRO<br/>Ryzen 7 PRO 8845HS"]

    LOADS --> MON1["UPERFECT Delta Pro Touch<br/>16″ 2.5K × 1"]
    LOADS --> MON2["UPERFECT Delta Pro Touch<br/>16″ 2.5K × 1"]

    LOADS --> ROUTER["GL.iNet Beryl AX"]

    LOADS --> USB["USB / прочая<br/>периферия"]
```

## 2. Силовая часть UPS
```mermaid
flowchart LR

    %% ===== AC INPUT =====

    AC["230 В AC"] 
        --> F1["F1<br/>Входной предохранитель"]
    F1 --> SW1["SW1<br/>Выключатель"]
    SW1 --> EMI["EMI-фильтр<br/>+ защита от импульсов"]

    EMI --> PSU["Mean Well<br/>28–30 В DC<br/>150–180 Вт"]


    %% ===== DC INPUT =====

    PSU --> D1["Ideal Diode / OR-ing<br/>обратный ток блокирован"]


    %% ===== SOLAR =====

    SOL["Солнечная панель"] 
        --> MPPT["MPPT / Solar DC-DC"]
    MPPT --> D2["Ideal Diode / OR-ing"]


    D1 --> BUS["DC POWER BUS<br/>≈ 24–28 В"]
    D2 --> BUS


    %% ===== CHARGING =====

    BUS --> CHG["CC/CV Charger<br/>25,2 В / 4 А"]

    CHG --> BMS["6S BMS"]

    BMS --> BAT["6S6P Li-ion<br/>21,6 В nominal<br/>25,2 В full"]


    %% ===== BATTERY OUTPUT =====

    BAT --> F2["F2<br/>DC предохранитель"]
    F2 --> SW2["SW2<br/>Battery Disconnect"]

    SW2 --> BB["Buck-Boost<br/>19,0 В / до 8 А<br/>≈150–200 Вт"]


    %% ===== OUTPUT OR-ING =====

    BUS --> CONV["DC/DC<br/>стабилизация 19 В"]

    CONV --> D3["Ideal Diode / OR-ing"]
    BB --> D4["Ideal Diode / OR-ing"]

    D3 --> OUT["19 В UPS OUTPUT"]
    D4 --> OUT


    %% ===== LOAD =====

    OUT --> F3["F3<br/>Выходной предохранитель"]

    F3 --> PC["AOOSTAR GEM12+ PRO<br/>19 В DC"]


    %% ===== OPERATION =====

    BUS -. "Сеть / солнце доступны" .-> D3
    BAT -. "Сеть пропала" .-> D4
```

## 3. Распределение питания
```mermaid
flowchart TB

    %% ===== UPS INPUT =====

    UPS["19 В UPS BUS<br/>стабилизированные"]

    %% ===== MAIN PC =====

    UPS --> F_PC["Предохранитель<br/>ветви PC"]
    F_PC --> PC["AOOSTAR GEM12+ PRO<br/>Ryzen 7 PRO 8845HS<br/>19 В / до 8 А"]

    %% ===== MONITORS =====

    UPS --> MON_DC["DC/DC для мониторов<br/>точное напряжение<br/>по требованиям UPERFECT"]

    MON_DC --> F_M1["F1<br/>предохранитель"]
    F_M1 --> M1["UPERFECT Delta Pro Touch<br/>16″ 2.5K"]

    MON_DC --> F_M2["F2<br/>предохранитель"]
    F_M2 --> M2["UPERFECT Delta Pro Touch<br/>16″ 2.5K"]


    %% ===== ROUTER =====

    UPS --> ROUTER_DC["DC/DC / USB-C PD<br/>для роутера"]

    ROUTER_DC --> ROUTER["GL.iNet Beryl AX"]


    %% ===== USB =====

    UPS --> AUX["DC/DC auxiliary<br/>5 В / USB"]

    AUX --> USB1["USB-порты"]
    AUX --> USB2["Зарядка смартфона"]
    AUX --> USB3["Прочая периферия"]


    %% ===== OPTIONAL =====

    UPS --> SPARE["Резервный DC выход<br/>будущая нагрузка"]


    %% ===== MONITOR RELATION =====

    M1 -. "DisplayPort / USB-C" .-> PC
    M2 -. "DisplayPort / USB-C" .-> PC

    ROUTER -. "Wi-Fi / Ethernet" .-> PC
```

| PC input        | 19 V / до 8 A                    |
| PC power        | до 150–200 W                     |
| AC PSU          | 28–30 V / 150–180 W              |
| Router          | GL.iNet Beryl AX                 |
| Displays        | 2 × UPERFECT Delta Pro Touch 16" |
